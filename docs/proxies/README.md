# Proxies Docs

Proxies is a separate product area from Numbers and Digital products.

## Active Decision

Proxies should eventually have:

- a web surface,
- APIs suitable for internal bots and future customer integrations,
- shared backend services for catalog, quote, rent, refresh/change, telemetry, and validation.

## Current Docs

- `WISHLIST_DEFERRED.md`: intentionally deferred proxy product ideas.

## Current Priority

Keep the current proxy product simple. Do not start deferred scheduling/fairness/rotation monetization ideas until the API-first platform work is further along.
